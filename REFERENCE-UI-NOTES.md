# MithraQ Reference UI Update

The mobile visual layer now follows the supplied MithraQ screenshots:
- blue Android/PWA theme color
- MithraQ logo area at the top
- purple-to-pink balance card
- three white summary cards
- rounded Budget Progress / Money Health / Quick Insights cards
- fixed 5-item bottom navigation with orange center Menu button
- white bottom-sheet Menu with Money / Planning / Insights / Personal File sections
- circular emoji/icon surfaces inside bordered menu tiles

Existing application data is not migrated, reset, or cleared by this visual update.
The Settings "Clear all data" action is also non-destructive in this build and reports that data protection is enabled.
