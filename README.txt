MithraQ Document Vault update

Added as a separate Menu item (not inside Settings).

Features:
- Document name and category
- Document date and optional expiry date
- Local document storage using IndexedDB
- Image/PDF/document file support up to 8 MB per file
- View and download
- Search
- Delete
- English/Tamil/Telugu/Kannada/Hindi labels

Existing finance data/UI modules are preserved in this update.
